AGGREY MEMORIAL WEBSITE PACKAGE
==============================

FILES
- index.html : page structure and website content
- style.css : styles, colors, layout and mobile responsiveness
- script.js : navigation menu, demo portal, gallery lightbox and button actions
- manifest.json : installable web app metadata
- service-worker.js : offline caching (works when served over HTTPS or localhost)
- images/ : 10 photos uploaded by the user, renamed and organized for the page

HOW TO OPEN
You can open index.html locally to preview the website. Some PWA/offline/install
features require hosting over HTTPS (for example GitHub Pages) or a local server.

HOW TO PUBLISH
Upload the package contents (index.html, style.css, script.js, manifest.json,
service-worker.js and images folder) into your web host's site root. Do not upload
only index.html or the images will not load. Keep the images folder alongside the
other files.

IMPORTANT
This is a school-information website prototype built from user-provided text and
photos. School facts, contacts, dates, programme availability, dormitory details,
and official status were not independently verified. Confirm content with school
management before publicly presenting it as official. The Student Portal is a
fictional front-end demo with sample names and grades; it is not secure and must
not be used with real student data or passwords.
